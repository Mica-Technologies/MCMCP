# Documentation site toolchain.
#
# Contributors do not need this to edit docs — every page is plain Markdown that renders on
# GitHub. It is needed only to preview the built site locally:
#
#   python -m pip install -r docs/requirements.txt
#   mkdocs serve
#
# Pinned to a major line rather than an exact version: the site is rebuilt from scratch on every
# deploy, so a patch release picked up by CI is a fix, not a surprise. A major bump is not.
#
# The `<2` on mkdocs is load-bearing, not boilerplate. MkDocs 2.0 removes the plugin system and
# rewrites theming with no migration path, so it would break this site outright the first time CI
# resolved it. Revisit only with mkdocs-material's own guidance in hand.
mkdocs>=1.6,<2
mkdocs-material>=9.5,<10
